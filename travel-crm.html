Everything Already Built

Lead Pipeline

NEW → CONTACTED → QUALIFIED → PROPOSAL_SENT → NEGOTIATION → CONVERTED

Every enquiry tracked across 7 stages. Assign agents, set follow-up dates, add notes. Nothing slips through.

  • Agent assignment + ownership tracking
  • Follow-up reminders via in-app notifications
  • One-click lead → booking conversion

Itinerary Builder

DRAFT → SENT → VIEWED → APPROVED → CONVERTED

Day-by-day planner with pricing engine. Send a public proposal link — customer views and approves online. Auto-converts to booking on approval.

  • Pricing engine with markup calculation
  • Professional PDF proposal export (pdfmake)
  • Public proposal page — no login needed to view

Tour Management

DRAFT → REVIEW → LIVE

Build tour packages with multiple pricing tiers. Manager approval before going live. Agents only ever see approved, live tours.

  • Multiple pricing tiers per tour
  • Manager approval workflow
  • Published to customer-facing website

Booking Lifecycle

DRAFT → PAYMENT_PENDING → PARTIALLY_PAID → FULLY_PAID → CONFIRMED → COMPLETED

Full lifecycle tracking from draft to trip completion. Auto-calculates base price, markup, and GST. Invoice PDF generated on confirmation.

  • Auto GST calculation on every booking
  • Invoice PDF generated instantly (pdfmake)
  • Status change triggers agent notifications

Payments + Razorpay

PENDING → PARTIAL → FULL

Online payments via Razorpay integration + offline (cash, UPI, NEFT, cheque). Partial payment tracking with outstanding balance calculation.

  • Razorpay online payment integration
  • GST tracking with IGST/CGST/SGST split
  • Tally-compatible GST summary CSV export

Commission System

PENDING → APPROVED → PAID

Commissions auto-created when booking is confirmed. Agent submits for approval → Manager approves → Finance marks paid. No more month-end disputes.

  • Auto-creation on booking confirmation
  • WhatsApp + in-app alerts at every step
  • Agent commission leaderboard in reports

Reports Dashboard

5 report types with date-range filters and CSV export. Real-time dashboard with live polling every 30 seconds.

  • GST Summary — IGST / CGST / SGST split
  • Aging Report — outstanding receivables
  • Agent Commission Report + leaderboard
  • Payment Methods breakdown

Customer Portal

Your own public-facing website. Customers browse tours, book directly, and pay via Razorpay — without calling or emailing.

  • OTP login + Gmail OAuth (Google sign-in)
  • Browse tours, view details, book online
  • View booking history, download invoices
  • Pay online via Razorpay

Notifications + Audit

Real-time in-app alerts powered by an email queue (Bull/BullMQ). Every action logged in an immutable audit trail.

  • In-app notification bell with read/unread
  • Email alerts via Bull queue + Handlebars templates
  • Full audit trail — user, timestamp, action
